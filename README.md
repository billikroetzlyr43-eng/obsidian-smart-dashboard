# Smart Dashboard

A magnetic-tile smart dashboard plugin for Obsidian. Nine live cards arranged on a 4-column square grid — calendar, quick jot, vault-wide search, stats, LLM token usage, schedule, todos and an A-share trading watchlist — with **proportional content scaling** so every tile always fits its cell (no scrollbars, no distortion), long-press drag rearrangement, and persistent layout.

## Features

| Card | Size | What it shows |
|---|---|---|
| Calendar | 2×2 | Month/week view of your vault schedule |
| Quick Jot | 1×1 | Fast capture box |
| Vault Search | 1×2 | Full-vault search |
| Create | 1×1 | Quick note creation |
| Stats | 2×1 | Vault statistics & charts |
| Token Usage | 2×1 | LLM token consumption (from `.smart-dashboard/usage_daily.json`) |
| Schedule | 1×1 | Upcoming schedule items |
| Todos | 1×1 | Task list with subtasks |
| Trading | 2×2 | A-share market watch tiles (index / ETF quotes) |

## Tile system

- **4-column square grid** — cells are computed from the container by `ResizeObserver` (design baseline 300px/cell, 12px gap). Below 900px it falls back to a 2-column flow.
- **Proportional scaling** — card content is scaled with `transform: scale()` to fit the cell completely: full content, no internal scrollbars, no distortion. Statistics tiles compress their header to give charts more room.
- **Long-press 500ms to drag** — rearrange tiles; the grid pushes the rest back into place.
- **Persistent layout** — positions are saved to `data.json` (`cardLayout`), restored on reload. A "Reset layout" button in the header restores the default arrangement.
- **Click suppression** — the click right after a drag ends is swallowed so you don't accidentally trigger card elements.

## Token usage card

Reads `.smart-dashboard/usage_daily.json` from the vault root (generated by a companion log-parsing collector — parse your own agent/LLM logs into this shape):

```json
{
  "2026-08-15": { "tokens": 123456, "cost_usd": 0.42 }
}
```

Keys: date → `{ tokens, cost_usd }` (both optional per day). The card renders daily bars plus a 7/30-day total view.

## Trading card

A-share index/ETF watchlist tiles. Data sources are wired in code (Sina/Tencent quote endpoints); the card supports keyword filtering.

## Build & install

```bash
npm install
npm run build   # node esbuild.config.mjs production
```

Copy `main.js`, `manifest.json`, `styles.css` into `<vault>/.obsidian/plugins/obsidian-smart-dashboard/`, then enable the plugin in Obsidian settings. (Or install via BRAT with this repository URL.)

## Requirements

- Obsidian ≥ 1.4.0
- Node.js ≥ 18 for building
